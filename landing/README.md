# CyberTree Landing Page

Brutalist-style landing page for CyberTree - Neural-Powered File Structure Generator

## Features

- 🎨 **Cyberpunk Brutalist Design** - Bold, raw aesthetics with strong borders and high contrast
- 📱 **Fully Responsive** - Works on desktop, tablet, and mobile devices
- ⚡ **Zero Dependencies** - Pure HTML/CSS with Astro for optimal performance
- 🔍 **SEO Optimized** - Proper meta tags and semantic HTML
- 🖼️ **Hero Screenshot** - Full-width app showcase
- 🔗 **Direct Links** - Quick access to GitHub and installation
- 👨‍💻 **Author Profile** - Featured credits and social links

## Tech Stack

- **Astro** - Static site generator
- **Pure CSS** - No framework overhead
- **Google Fonts** - Rajdhani (headings) & Fira Code (code)
- **Inline Styles** - Single file, no external CSS

## Getting Started

### Install Dependencies

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

## Customization

### Colors

The theme uses cyberpunk colors:

```css
--primary: #ffdb89 (Gold accent)
--bg: #050505 (Dark background)
--card-bg: rgba(26, 26, 28, 0.8) (Card background)
--text: #ffffff (White text)
--secondary: #888888 (Gray text)
```

### Fonts

- **Rajdhani** - Tech-styled headings (500, 600, 700 weights)
- **Fira Code** - Monospace for code elements (400, 500 weights)

### Sections

1. **Header** - Navigation with GitHub link
2. **Hero** - Main title, subtitle, and screenshot
3. **Features** - 6 feature cards with hover effects
4. **Tech Stack** - Technology badges
5. **Installation** - Code blocks with copy-ready commands
6. **Author** - Credits and social links
7. **Footer** - Copyright info
